# HR Analytics Dashboard

HR Analytics Dashboard using Power BI.

## 📌 Project Overview
This project analyzes employee data to understand workforce trends and employee attrition.

## 🛠️ Tools Used
- Microsoft Power BI
- Microsoft Excel

## 📊 Dashboard Features
- Total Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Monthly Income
- Employee Count by Department
- Employee Attrition by Gender
- Employee Attrition by Age
- Employee Attrition by Education Field

## 🎯 Project Objective
To analyze employee data and understand employee attrition patterns through interactive visualizations.
